# 合耕小舍 · 竖版农场 H5 Demo

本轮采用暖黄色界面：顶部渐变、白灰分组与黄底深字按钮，底部五项等宽，仅当前图标填黄。“主页”聚合签到、论坛圈子、好友与动态；“我的”集中资产、每日签到与服务入口。社区可发帖配图、点赞评论、分享示例内容；好友可申请/接受/取消/移除、查看示例个人田园。所有社交只保留本页，刷新重置，不上传或向真人发送；[完整说明](../docs/SOCIAL.md)。旧activities仍能进入完整活动中心。

第五轮新增：积分商品搜索与四种筛选、心愿清单和攒分目标、任务资格筛选、七日奖励逐日预览。可先在“积分好礼”打开100积分相框，设为目标，再去活动签到查看同一余额进度。心愿、查询和目标均刷新清空，不自动兑换。

面向 30–50 岁及中老年用户的手机竖版体验：种养照料、积分商城、社交活动、仓库成长、农场实景与收获到家。本轮底部为“我的农场／商城／主页／实景／我的”；价格、库存、周期、收益、频次和奖励均为 Demo 样本。

## 本地启动

在项目根目录运行：

```powershell
python prototype/serve.py
```

打开 [合耕小舍本地 Demo](http://127.0.0.1:4173/)，按 `Ctrl+C` 结束服务。无需前端依赖或登录。当前为单一成熟竖版方向，不再提供旧三种首页链接。

## 体验路线

1. 在“我的农场”切换农田／牧场，查看自己的作物、牲畜、生长状态、等级和每日农事。
2. 打开“商城”的“当季认养”，比较推荐、时令理由、周期和收获参考价值；从空地选种或推荐入口进入时会直接回到当季认养，完成原模拟认养订单。
3. 切到“农场物资／积分好礼”，查看 8 种积分商品、数量和当日库存；加入购物车，比较满 60 减 20 积分券、余额与应付积分，体验成功及余额不足等失败路径。资源发到同一钱包／仓库，没有现金支付。
4. 从“主页”进入“更多活动”，体验七日连续签到、每日逛商城／照料／收获三任务、丰收三印章和四个成长成就。任务先完成再领取，三项当天任务都领取后才能领集章礼，重复点击不重复发奖。
5. 返回农场浇水或投喂，查看次数、间隔与设备忙碌原因；体验在线、离线和无回执。成功照料才计任务，福利和购买饲料不解除冷却。
6. 打开“实景”，切换农田、牧场和猪第一视角；原广告／邀请福利及真实 H5 分享／复制入口继续可用。
7. 收取鸡蛋或选择成熟对象预约采收／处理，再使用示例邮寄信息查看脱敏摘要和模拟履约。首次完成采收／处理才累计收获，预约和运输步骤不重复计入。
8. 从农场或“我的”查看仓库、累计收获、等级进度、种养图鉴和消息中心；比较购物、任务奖励与原投喂所用的同一份饲料余额。

## 数据与模拟边界

设备、摄像头、工作人员任务、商品金额、产量／收益、广告、邀请、订单与物流均为模拟。只有实际 H5 URL 的公开访问、系统分享或复制可真实使用；分享成功不代表产生有效拉新。

积分商品、满减券、库存、经验和奖励都是演示配置。原认养展示示例金额，新增商城仅结算虚拟积分；余额、库存、用券和发资源一起成功才算结算完成，失败不扣分不发资源。签到按上海日期，同日不可重领，连续中断开新轮次，不能回退日期刷奖励。

灌溉须收到模拟回执后才开始计时；无回执不显示成功、不自动重试、不增加湿度。浇水和投喂有 Demo 次数及间隔，福利不能绕过这些限制。

邮寄请只用示例信息。原始输入不外发、不进 storage、URL 或日志，确认后只在内存留下脱敏摘要。业务状态只在当前页面内存保存，刷新会重置；这不代表对真实设备执行停止。

## 开发入口

vanilla HTML／CSS／JavaScript；`domain.js` 管理原规则，`systems.js` 的 `FarmSystems` 管理商城和活动，`ui.js` 提供共享操作SVG及摄影图，`app.js` 拥有主状态与共享模态，`expansion.js` 接入扩展。`styles.css` 拥有运行时 token，`expansion.css` 消费这些 token，Python 仅提供本地静态服务。

仓库内自动检查：

```sh
node --test
node --check prototype/app.js
node --check prototype/ui.js
node --check prototype/domain.js
node --check prototype/systems.js
node --check prototype/expansion.js
```

本轮已执行测试记录为 43 项：18 项原领域、22 项系统规则、3 项扩展集成回归。发布前重跑和新版浏览器／部署结果由验收记录汇总，不将测试通过当作界面或平台验收。
