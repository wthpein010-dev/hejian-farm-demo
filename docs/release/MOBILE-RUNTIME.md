## 继续运行的条件

微信自动化需要用户在开发者工具内完成登录，并自行在“设置 → 安全设置”开启“服务端口”。之后仅针对本工程连接工具，先验证访客配置能否编译、页面能否加载，再分别核验正式 AppID、基础库、HTTPS 合法域名、身份、分享和真机。当前没有取得这些结果。

App 需要与当前编译器匹配的官方 uni-app 原生运行时/打包链，采用 HBuilderX 或官方离线 SDK；现有 Unity Android 工具不足以直接生成有效的 uni-app 安装包。独立调试包可先做模拟器验收；正式版本另需用户归属的平台标识、包名/Bundle ID、签名及实体手机验证。秘密通过安全配置进入打包或服务端环境，不写入聊天、前端变量、源码或日志。

公开 H5 仍为页面内存演示；持久社区/农友只在开发沙盒验证。生产 API、真实审核人员/内容安全、官方平台分享与邀请归因、农场设备/视频/支付/履约和正式上架仍按 [READINESS](READINESS.md) 保留未完成状态。
