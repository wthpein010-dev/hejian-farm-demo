## 后续运行门槛

微信服务端口与登录按用户决定暂缓；恢复此项时只连接本工程，不降低域名校验。此前微信CLI失败分支退出0，必须结合输出、实际连接和页面状态判断，不以退出码单独判成功。

Android后续需先解决官方launcher激活/设备发现与Node版本，再将当前工程同步到明确归属的实例，验证实际页面、文字输入、返回与草稿、软键盘、安全区及网络恢复。不能默认选第一台设备，也不能把标准基座改称独立安装包。正式版本仍须用户归属的AppID、包名/Bundle ID、签名和实体手机验证。

小程序code2Session只适用于相应小程序。App OAuth及跨平台资产共享必须有明确的提供方与账户绑定协议，不能复用小程序code或按显示名/手机号猜测合并账户。秘密只进入安全的打包或服务端配置，不写入聊天、前端变量、源码或日志。

公开H5仍是页面内存演示。持久论坛、农友、播种和每日收蛋只在开发沙盒验证；生产API、真实运营与农场能力、签名真机及平台审核仍按[READINESS](READINESS.md)保持未完成。
