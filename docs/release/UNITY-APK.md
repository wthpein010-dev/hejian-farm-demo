# 合耕小舍 · Unity 安卓体验版

本轮来源：2026-10-31用户要求“将这个内容用Unity进行开发，打一个APK的包”。这是原生Unity/C#的离线体验分支，独立于既有H5与uni-app账户工程，不改变原正式上线验收状态。

## 内容

- 五入口：我的农场、商城、主页、实景、我的；暖黄主题、大字操作、写实照片，默认进入主页。
- 农田/牧场、地块选择、种养认领、手动收获、鸡蛋收取、仓库和示例配送。
- 浇水启动确认、发送/启动回执/执行/停止回执、离线/无回执核查；照料每天2次、浇水6小时/投喂4小时间隔，福利不能解除限制。
- 当季排序、9种种养示例、8种积分商品、购物车、满60减20积分券、原子兑换和完整收据。
- 七日签到、每日任务、新人礼、模拟广告、社区圈子、动态/评论/点赞、示例好友和系统分享公开H5入口。
- 25张既有摄影示意及Noto Sans CJK SC开源字体；来源和许可证随工程交付。图片不是农场实拍或直播。

## 工程归属

`unity/Assets/Scripts/FarmModel.cs`拥有进程内钱包与规则；`FarmUI.cs`拥有UGUI共享组件；`FarmApp.cs`组合页面和内存社区。`prototype/styles.css`经`tools/sync-unity-theme.mjs`生成`FarmTheme.cs`。照片从原WebP等尺寸转换JPG并逐份核对摘要，`FarmPhotoImport`统一Sprite导入。

用Unity2022.3.62f3c1打开`unity/`，进入Play模式即可体验。安卓构建方式与环境、资源核验、签名检查见[工程说明](../../unity/README.md)。包名`com.hegeng.xiaoshe.demo`，Android7/API24起、目标API34，IL2CPP ARM64/ARMv7；本地体验签名与生产签名分开。

## 数据与上线边界

全部业务、UGC和草稿仅进程内保留，完全退出重置。示例收货资料不外发、不落盘，确认后只保留脱敏摘要；配送流程不发真实运单，也不扣仓库。分享使用固定公开入口，不携带帖子/草稿/收货资料，也不自动产生拉新奖励。

本包未接入微信身份、真实农事/设备、摄像头、广告SDK、支付或物流；不自动创建另一套生产资产。App与小程序账户共用方案、开放平台配置及真实服务仍需按[上线矩阵](READINESS.md)继续核定。UGUI的系统读屏、大字与软键盘须专项真机验收；编辑器截图、C#检查和APK验签分别证明对应范围。
